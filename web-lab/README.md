# Git Flow Lab

A simple web project for practising Git workflows.

## Features

- Responsive header with navigation links.
- Dark mode toggle button in the header.
- JavaScript interaction to switch between light and dark themes.

## Dark Mode

Click the "Toggle dark mode" button in the header to enable
dark mode. Click it again to return to the light theme.

The theme is controlled by the `data-theme` attribute on
the HTML body element.
